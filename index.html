Mini-Projet - Analyse d'URLs

À propos du projet

Ce projet analyse des URLs et montre les résultats dans un tableau.

D'abord, on a écrit un script qui générait un fichier TSV. Ensuite, on l'a modifié pour créer une page HTML à la place. Et maintenant on utilise Bulma pour que ça soit joli.

Ce que fait le script

Pour chaque URL, le script regarde :

  • Le code HTTP (200, 404, etc.)
  • L'encodage de la page
  • Le nombre de mots
